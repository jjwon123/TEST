# Fail Cases

## Blocking Failures

- Missing approved brief
- Unsupported channel with no fallback rule
- Deliverable with no visual need or content purpose

## Review Failures

- Too many deliverables for the event's operational scope
- Missing mandatory announcement format
- Template mismatch between desired ratio and available Figma metadata

## Retry Rules

On retry, preserve deliverable IDs unless the deliverable is removed. New deliverables receive new IDs and should not overwrite previous assets.
