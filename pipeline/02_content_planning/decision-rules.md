# Decision Rules

## Deliverable Fit

A deliverable is valid only when it has a channel, audience moment, content role, visual need, and expected output format.

## Priority

1. Required operational announcement assets
2. Primary acquisition or participation assets
3. Supportive explanation assets
4. Optional variants

## Channel Discipline

Do not duplicate the same message across every channel. Adjust content structure to the channel's natural behavior and template limits.
