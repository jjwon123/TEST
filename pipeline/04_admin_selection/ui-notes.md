# UI Notes

## Candidate Grid

Group by deliverable and visual role. Each card should show preview, ratio, source prompt, current decision, and warning badges.

## Comparison

Managers need side-by-side comparison for variants. Show selected state persistently and prevent accidental replacement without confirmation.

## Regeneration

Regeneration requests should be structured, not free-form only. Capture what to keep, what to change, and whether the current candidate should remain available.
