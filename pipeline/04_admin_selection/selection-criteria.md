# Selection Criteria

## Select

Choose a candidate when it fits the brand, supports the event message, leaves room for text, and can work in the target channel ratio.

## Reject

Reject a candidate when it is off-brand, confusing, visually noisy, legally risky, low quality, or unsuitable for text overlay.

## Regenerate

Request regeneration when the concept is correct but execution fails, or when all candidates for a deliverable miss the required role.

## Hold

Use hold only when a decision depends on a pending brief, legal, or stakeholder answer.
