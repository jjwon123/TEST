# Handoff

`05_figma_assembly` receives only selected assets and explicit regeneration notes. The assembly stage should treat selection as binding unless a selected file is missing or fails template constraints.

## Required Handoff Fields

- `deliverable_id`
- `candidate_id`
- `selected_file`
- `usage`
- `manager_note`
- `text_overlay_risk`
- `approval_status`
