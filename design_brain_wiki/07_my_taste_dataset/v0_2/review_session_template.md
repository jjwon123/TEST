# Review Session Template

목적: 기원님이 실제 레퍼런스를 보면서 판단한 내용을 일관되게 기록한다.

## Session Info

```text
date:
profile:
eventType:
channel:
referenceSource:
reviewer:
```

## Batch Summary

```text
totalReviewed:
selected:
shortlist:
rejected:
mostCommonGoodSignal:
mostCommonBadSignal:
mostConfusingBoundary:
ruleToUpdate:
```

## Per Reference

```text
id:
file/url:
decision:
role:
whatWorks:
whatFails:
whySelectedOrRejected:
usableFor:
riskSignals:
kiwonFeedback:
wikiRuleToUpdate:
```

## Decision Labels

- `selected`: 실제 방향 기준으로 삼아도 된다.
- `shortlist`: 일부 기준만 참고한다.
- `rejected`: 브랜드/이벤트/업종 신뢰를 해치므로 버린다.

## Review Prompts

- 이 이미지를 우리 브랜드가 써도 되는가?
- 어떤 부분만 참고할 수 있는가?
- 왜 메인으로는 안 되는가?
- 이 이미지를 따라 만들면 어떤 문제가 생기는가?
- 카피/CTA/채널 변환이 가능한가?
