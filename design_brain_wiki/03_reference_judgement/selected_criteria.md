# Selected Criteria

## 자료 원문/링크

- IBM Carbon Design System: https://carbondesignsystem.com/
- Apple Human Interface Guidelines: https://developer.apple.com/design/human-interface-guidelines/
- Interbrand: https://interbrand.com/

## 핵심 요약

selected reference는 최종 결과물에 방향을 직접 줄 수 있어야 한다. 예쁜 이미지가 아니라 브랜드, 이벤트, 채널, 제작 실무성이 함께 통과되어야 한다.

## 디자인 판단 질문

- 브랜드 성격과 업종 신뢰를 동시에 만족하는가?
- 이벤트 목적이 읽히는가?
- 카피와 CTA를 넣을 실무 공간이 있는가?
- 같은 방향으로 여러 산출물을 만들 수 있는가?

## 평가 항목

- `brandFit >= 8`
- `eventFit >= 8`
- `industryTrust >= 7`
- `layoutUsability >= 7`
- `copySpace >= 6`
- `cheapSignalRisk <= 3`

## good/bad 적용

- good: selected는 "방향 기준"으로 반복 사용 가능해야 한다.
- bad: 일부 요소만 좋은 이미지는 selected가 아니라 shortlist다.

## AI 피드백 문장 예시

- 브랜드 톤, 업종 신뢰감, 카피 여백이 함께 살아 있어 selected reference로 두기에 적합합니다.
