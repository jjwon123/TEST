# Source Map

이 파일은 위키의 1차 공식/신뢰 출처 지도다. 각 출처는 원문을 그대로 모으기보다 판단 기준으로 변환해서 사용한다.

- IDEO Design Thinking: https://designthinking.ideo.com/
- IDEO.org Tools / Design Kit: https://www.ideo.org/tools

## 사용 원칙

1. 출처는 권위 확인용이다.
2. 위키 본문은 출처의 문장을 복사하지 않고, AI 판단 질문과 평가 항목으로 재구성한다.
3. 실제 프로젝트 판단은 `assets/rules`, `assets/reference_training`, `design_brain_wiki`를 함께 사용한다.
