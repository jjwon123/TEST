# Selected Feedback

## 목적

selected feedback은 칭찬이 아니라 "왜 이 방향을 기준으로 삼아도 되는지"를 설명해야 한다.

## 문장 구조

```text
이 레퍼런스는 [핵심 강점] 때문에 [브랜드/이벤트 목적]에 적합합니다.
[실무 적용 근거]가 있어 [채널/산출물]로 확장하기 좋습니다.
```

## 예시

- 이 레퍼런스는 제품의 금속 재질과 절제된 여백이 살아 있어 금 투자 상담 이벤트의 프리미엄 신뢰감에 적합합니다.
- 헤드라인 영역과 제품 영역이 분리되어 있어 인스타그램 카드뉴스 메인 비주얼로 확장하기 좋습니다.
- 색 사용이 제한적이고 업종 신뢰감을 해치지 않아 selected 기준으로 둘 수 있습니다.

## 평가 항목 연결

- `brandFit`
- `eventFit`
- `industryTrust`
- `layoutUsability`
- `copySpace`
