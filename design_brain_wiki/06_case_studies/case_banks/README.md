# Case Banks v0.2

목적: 유명 스튜디오 사례를 단순 링크가 아니라 `Reference Judge`가 쓸 수 있는 판단 근거로 바꾼다.

## 케이스 변환 포맷

```text
문제:
브랜드 판단:
시각 시스템:
왜 맞았나:
에이전트 판단 기준:
피드백 문장:
```

## 현재 수량

- Pentagram: 10개
- COLLINS: 10개
- Wolff Olins: 10개
- Landor: 10개
- Interbrand: 10개

총 50개.

## 사용법

1. Reference Judge가 업종/브랜드 문제와 가까운 case bank를 찾는다.
2. 케이스의 `에이전트 판단 기준`을 scoring field로 변환한다.
3. 피드백 문장은 그대로 복사하지 않고 현재 브랜드/이벤트 문맥에 맞춰 재작성한다.
