# Senior Designer Brain Wiki

목적: AI가 브랜드, 이벤트, 레퍼런스를 시니어 디자이너처럼 판단할 수 있도록 디자인 원칙, 브랜드 전략, UX 기준, 업종별 playbook, 사례 연구, 기원님 취향 데이터를 구조화한다.

이 위키는 링크 모음이 아니다. 모든 문서는 아래 변환 구조를 따른다.

```text
자료 원문/링크
→ 핵심 요약
→ 디자인 판단 질문
→ 평가 항목
→ good/bad 사례 적용
→ AI 피드백 문장 예시
```

## 폴더 구조

- `01_design_principles`: 계층, 그리드, 타이포그래피, 컬러, 여백, 구도.
- `02_brand_strategy`: 브랜드 성격, 시스템성, 차별성, 일관성, 프리미엄/저렴함, 신뢰/과장.
- `03_reference_judgement`: selected, shortlist, rejected 판단 기준.
- `04_channel_usability`: 인스타그램, 카드뉴스, 배너, 블로그 썸네일, 랜딩 페이지 실무성.
- `05_industry_playbooks`: 업종별 판단 기준.
- `06_case_studies`: 스튜디오/디자인 시스템/UX 공식 자료를 판단 규칙으로 변환.
- `07_my_taste_dataset`: 기원님 직접 판단 데이터의 good/bad/shortlist/notes 축적.
- `08_feedback_language`: 시니어 디자이너처럼 설명하는 문장 라이브러리.
- `99_sources`: 출처 지도와 추후 수집 큐.

## 현재 1차 목표

1. 이미지 생성보다 먼저 브랜드/이벤트/레퍼런스 판단 기준을 고정한다.
2. 좋은 레퍼런스와 나쁜 레퍼런스를 단순 태그가 아니라 이유까지 저장한다.
3. AI 출력이 "예쁘다/별로다"가 아니라 실무 판단 문장으로 나오게 한다.
4. 이후 `03_reference_research`와 Reference Judge가 이 위키를 읽어 판단하도록 연결한다.

## 핵심 판단 축

- `brandFit`: 브랜드 성격과 맞는가.
- `eventFit`: 이벤트 목적과 맞는가.
- `industryTrust`: 업종 신뢰감을 해치지 않는가.
- `referenceRole`: 제품 정체성, 무드, 레이아웃 중 어떤 역할인가.
- `layoutUsability`: 실제 카드뉴스/배너/포스터로 쓸 수 있는가.
- `copySpace`: 한국어 헤드라인과 CTA가 들어갈 여백이 있는가.
- `premiumSignal`: 고급감이 구조/재질/여백/조명으로 설득되는가.
- `cheapSignalRisk`: 장식, 과장, 가짜 텍스트, 장난감 같은 신호가 있는가.
