# Brand Event Console

Local operator dashboard for the event content automation pipeline.

Start it from the project root:

```bat
start_brand_event_console.bat
```

Then open:

```txt
http://127.0.0.1:5177
```

The console reads `runs/`, creates new `events/` folders, launches existing batch/python workflows, and writes `run-manifest.json` files for UI status.
