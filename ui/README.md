# UI

The UI layer is reserved for operator review and decision surfaces.

The active local dashboard implementation is:

- `ui/console/`
- `scripts/console_server.py`
- `scripts/run_manifest.py`
- `start_brand_event_console.bat`

For current UI handoff, read:

- `docs/BRAND_EVENT_CONSOLE_HANDOFF.md`
- `docs/HANDOFF_INDEX.md`

Initial screens should map directly to pipeline contracts:

- dashboard: run status and approvals
- event-brief: brief review
- content-planning: deliverable plan review
- candidate-selection: visual candidate decisions
- figma-assembly: template and export status
- qa-review: QA issues and approval
- asset-library: archived reusable assets
