# 모델 테스트 기록

이 문서는 LM Studio, 로컬 LLM, 이미지 모델, ComfyUI 워크플로의 테스트 결과를 기록하는 곳이다.

## 기록 원칙

- 성공한 테스트만 남기지 않는다.
- 실패한 조건, 출력 문제, 수정 방법을 함께 남긴다.
- 모델명, 날짜, 입력, 출력, 판단을 분리한다.
- 같은 이벤트에서 여러 모델을 비교할 수 있게 한다.

## 테스트 기록 템플릿

```text
날짜:
모델/워크플로:
목적:
입력:
결과:
좋았던 점:
문제:
다음 수정:
관련 파일:
```

## LM Studio 테스트

기록할 항목:

- 모델명
- 양자화 형식
- 컨텍스트 길이
- 한국어 기획 품질
- JSON 출력 안정성
- 브랜드 기준 준수
- 긴 문서 참조 성능

## 이미지 모델 테스트

기록할 항목:

- 모델명
- 프롬프트
- 네거티브 프롬프트
- 제품 유지력
- 텍스트 삽입 여백
- 채널별 구도 적합성
- 후보 다양성

## ComfyUI 테스트

기록할 항목:

- 워크플로 파일
- 주요 노드
- 입력 이미지
- 제품 고정 방식
- 배경 생성 방식
- 실패 조건
- 재사용 가능 여부

## 현재 우선 검증할 것

- 제품 이미지 형태를 유지한 상태에서 광고 배경만 바꾸기
- 채널별 카피 여백 확보
- 동일 이벤트에서 카드뉴스/피드/블로그 썸네일 톤 통일
- 로컬 LLM이 `brief.json`, `content-plan.json`을 안정적으로 생성하는지
