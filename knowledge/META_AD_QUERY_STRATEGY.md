# Meta Ad Library 검색 쿼리 전략

## 핵심 차이

Pinterest는 디자인 결과물 묘사형 검색이 잘 맞는다.

```text
스킨케어 이벤트 배너 디자인
화장품 카드뉴스 디자인
```

Meta Ad Library는 실제 광고주와 광고 카피를 검색한다.

```text
메디큐브
나이아신아마이드 세럼
스킨케어 세일
화장품 할인
```

따라서 Pinterest 검색어를 Meta에 그대로 사용하지 않는다.

## 권장 검색 구조

이벤트마다 아래 3축을 함께 수집한다.

1. 경쟁 브랜드: 실제 광고주의 캠페인 소재 수집
2. 상품/성분: 제품 표현과 효능 메시지 수집
3. 카테고리+혜택: 할인, CTA, 세일 정보 위계 수집

자사 브랜드 검색은 현재 광고 노출 여부 확인용으로만 사용한다.

## 운영 규칙

- 기본 검색 4개: 경쟁 브랜드 1~2개, 상품/성분 1개, 카테고리+혜택 1~2개.
- 쿼리당 광고 10개부터 시작한다.
- 수집량이 많아도 자동 선택하지 않는다.
- 기존 Reference Judge로 캐릭터, 인플루언서 중심, 잘못된 카테고리, 낮은 로컬 적합성을 거른다.
- 원본 광고를 복제하지 않고 혜택 위계, CTA, 레이아웃, 제품 표현 방식만 참고한다.

## 광고 성격 선택

검색어만으로는 원하는 이미지 성격을 통제할 수 없다. 검색 후 광고 성격 필터를 적용한다.

| 프로필 | 용도 | 자동 연결 기준 |
|---|---|---|
| 클린 제품 비주얼 | 이미지 생성 무드·제품 배치 참고 | Qwen 제품 중심 판정, 낮은 텍스트 밀도, 캐러셀/영상 제외 |
| 단일 광고 이미지 | 한 장짜리 실제 광고 참고 | 캐러셀/영상 제외, 텍스트 광고 포함 가능 |
| 브랜드 캠페인 | 모델·브랜딩·톤 참고 | 광고당 최대 3장 |
| 프로모션 구조 | 할인·혜택·CTA 구조 참고 | 광고당 최대 5장 |
| 전체 원본 | 조사·보관 | 필터 없음 |

경쟁 브랜드 검색 시에는 `검색어와 광고주명 일치`를 사용할 수 있다. 단, 브랜드명이 광고 카피에 언급되었지만 광고주는 다른 계정인 결과가 많으므로 결과가 0개일 수도 있다.

## 브랜드 검색 해석

- 특정 브랜드 검색은 소재 톤을 일정하게 만드는 데 유용하다.
- 하지만 Meta 검색은 해당 브랜드의 공식 광고만 반환하지 않는다.
- 리셀러, 인플루언서, 제휴 페이지가 브랜드명을 언급한 광고도 포함한다.
- 공식·직접 광고주만 원하면 `검색어와 광고주명 일치`를 켠다.
- 시장 전체의 표현 방식을 보고 싶으면 광고주 일치를 끄고 성분·혜택 쿼리를 사용한다.
