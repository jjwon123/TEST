# 프로젝트 목표

이 프로젝트는 이벤트 하나를 입력하면 채널별 콘텐츠 산출물 세트를 자동으로 만들 수 있게 하는 이벤트 콘텐츠 자동화 시스템이다.

## 해결하려는 문제

이벤트 콘텐츠 제작은 보통 다음 정보가 흩어진 상태에서 진행된다.

- 이벤트 기본 정보
- 브랜드 가이드
- 채널별 문안 규칙
- 이미지 프롬프트 규칙
- 이미지 후보와 선택 결과
- Figma 조립 기준
- QA 체크 기준
- 이전 성공/실패 사례

이 프로젝트의 목표는 이 흐름을 단계별로 정리하고, Codex와 AI가 각 단계 산출물을 만들며, 사람이 필요한 지점에서 승인과 선택을 할 수 있게 만드는 것이다.

## 핵심 결과물

- 이벤트 브리프
- 채널별 콘텐츠 플랜
- 이미지 생성 프롬프트 (ComfyUI 실행용)
- 이미지 후보 선택 결과
- QA 리포트
- 재사용 자산 아카이브

## 하지 않는 것

- `byextremeai/static-ads`를 완제품으로 복제하지 않는다.
- 고정 광고 템플릿만 대량 생성하는 시스템으로 만들지 않는다.
- 실행 스크립트 하나가 모든 AI 판단을 대신하게 만들지 않는다.
- 이미지 생성 엔진, Figma 조립, AI 생성 로직을 `scripts/workflow.py`에 밀어 넣지 않는다.

## 가져오는 패턴

`byextremeai/static-ads`에서는 다음 패턴만 참고한다.

- 단계 분리
- 승인 게이트
- JSON 중간 산출물
- 개별 재생성
- 버전 보존

도메인은 `event-content-pipeline`으로 새로 설계한다.

## 성공 기준

- 새 이벤트를 넣으면 1~5단계 산출물이 일관된 구조로 생성된다.
- 사람이 개입해야 하는 지점이 명확하다.
- 이전 실행 결과를 `runs/`에서 추적할 수 있다.
- 브랜드 기준, 프롬프트 기준, QA 기준이 Obsidian 문서와 프로젝트 파일에 함께 남는다.
- 나중에 LM Studio와 ComfyUI를 붙여도 기준 문서가 흔들리지 않는다.
